# Siddhant Magdum — Portfolio

Static HTML/CSS/JS portfolio with Three.js 3D background, GSAP scroll animations,
custom cursor, 3D tilt cards, typing effect, filters, timeline.


## Customize (replace dummy data)
- `index.html` → name, email, links, projects, experience, education
- `css/style.css` → colors in `:root`
- Resume button → point `downloadResume()` / Resume links to your real PDF

## Deploy to Vercel (recommended)
1. Push this `portfolio/` folder to GitHub
2. Go to vercel.com → Add New → Project → Import your repo
3. Framework Preset: **Other**, Root Directory: `portfolio` (if repo root contains it) or `./` if repo IS portfolio
4. Build Command: empty, Output: `.` → Deploy

## Deploy to GitHub Pages
Repo Settings → Pages → Deploy from branch → `main` / `/root` (or `/portfolio` via docs) — or use `gh-pages`.
